# ПодарокГид

Статический сайт с подборками идей подарков (партнёрский/контентный проект).
Собирается из Markdown-статей в готовый HTML и деплоится на GitHub Pages
через GitHub Actions — полностью автоматически, без хостинг-провайдера и
без сервера.

## Структура

- `content/published/` — опубликованные статьи (Markdown с front matter).
- `content/queue/` — статьи «про запас». Раз в неделю (по понедельникам)
  GitHub Actions автоматически берёт самую старую статью из очереди,
  проставляет ей текущую дату и публикует на сайте — без участия человека.
- `templates/base.html` — единственный HTML-шаблон страницы.
- `static/style.css` — стили сайта.
- `scripts/build.py` — генератор сайта: собирает `content/published/*.md`
  в готовый сайт в папке `public/`.
- `scripts/publish_next.py` — переносит одну статью из очереди в
  публикацию (запускается автоматически по расписанию).
- `scripts/generate_articles.py` — вспомогательный генератор, которым
  изначально была наполнена база статей. Можно использовать как пример,
  чтобы добавить новые статьи по той же схеме.
- `.github/workflows/publish.yml` — вся автоматизация: раз в неделю
  публикует статью из очереди и деплоит сайт на GitHub Pages. Также
  пересобирает и деплоит сайт при любом push в ветку `main`.
- `config.json` — настройки сайта и партнёрских ссылок.

## Как добавить партнёрские ссылки в статью

В тексте статьи (Markdown) используйте специальные псевдо-ссылки вида:

```
[Посмотреть на Ozon](ozon://https%3A%2F%2Fwww.ozon.ru%2Fsearch%2F%3Ftext%3D...)
```

При сборке сайта `build.py` автоматически превращает `ozon://...` и
`wb://...` в реальные партнёрские ссылки согласно `config.json` —
подставлять кампанию Admitad вручную в каждой статье не нужно.

## Обязательные разовые настройки (делает человек, не автоматизация)

1. В `config.json` заменить `REPLACE_OZON_CAMPAIGN_ID` / `REPLACE_WB_CAMPAIGN_ID`
   на реальные ID кампаний после одобрения в Admitad.
2. В `config.json` заменить `site_url` на реальный адрес сайта после
   подключения домена.
3. В настройках репозитория (Settings → Pages) выставить источник
   деплоя «GitHub Actions».

Полная пошаговая инструкция на русском языке — в отдельном файле,
который прилагается к проекту.

## Как добавить ещё статей в очередь

Скопируйте любой файл из `content/queue/` как образец, измените
`title`, `slug`, `description`, `category` и содержимое, сохраните
новый файл в `content/queue/` — он встанет в очередь на публикацию.
Ничего пересобирать вручную не нужно: следующий понедельник GitHub
Actions опубликует его сам.
